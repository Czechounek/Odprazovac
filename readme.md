# Odpražovač

Rozšíření do prohlížeče pro odstraňování obecné češtiny z vašich stránek.

## Vokno? A ven!

Snažíme se tímto rozšířením udělat ze světa lepší místo. Proto, po instalaci našeho odpražovače nikdy nemusíte znovu spatřit obecnou češtinu. 

Co umíme opravit:
- Fráze typu: "přijdu dýl"
- Přípony -ej → -ý
- Odstranění předpony vo- (vokno → okno, vod → od)
- Doplnění -l u příčestí minulého (řek → řekl, moh → mohl, pích → píchl)

Samozřejmě dbáme i na výjimky, aby žádný uživatel tohoto rozšíření nepřišel o bohatý kontext spisovného českého jazyka a vždy pochopil, co tím autor zamýšlel.

Nejsou shromažďována žádná data o opravách, pouze anonymní metrika o počtu opravených slov pro analytické účely.
